## ① 一投稿目（最重要・アカウントの顔）
```
「好きな人がいるって、こんなにしんどいんだ」

そう言って泣いてた知り合いがいる。

片思い3年。脈なし。叶わないってわかってるのに、好きをやめられない。
既読がつくだけで一喜一憂して、相手のストーリーを何回も見返して。

——これ、わかる人いるよね?

このアカウントは、そんな「片思い・好きな人・脈なし・叶わない恋」の話を、
知り合いから聞いたぶんだけ、ここに置いていく場所です。

しんどい夜に、そっと読みにきてね。
```

## ② 実話長文（ビフォーアフター×自分励まし）
```
知り合いに、5年も片想いしてた子がいる。

毎朝、好きな人より早く出勤して。
偶然を装って、エレベーターで一緒になるためだけに。

「脈なんてないよ」って笑ってたけど、
その子の努力、わたしは全部知ってた。

結果は——彼に彼女ができて、片思いは終わった。

でも最後にその子、こう言ったの。
「叶わなかったけど、あんなに本気で人を好きになれた自分のこと、ちょっと好きかも」って。

片思いって、報われなくても無駄じゃないのかもね。
```

## ③ 一言（短い・刺さる）
```
脈なしって、わかってるんだよ。
わかってるのに、好きなんだよ。

それが片想いの、いちばんしんどいところ。
```

## ④ 問いかけ（コメント誘発）
```
片思い中のみんなに聞きたい。

好きな人のこと、1日に何回考える?

知り合いは「数えたら100回超えてた」って言ってて、
それ聞いて——あ、わたしだけじゃないんだって、ちょっと安心した。

脈なしでも、叶わなくても、好きな人を想う時間って、なんでこんなに増えるんだろうね。

みんなは、何回?
```

## ⑤ 実話（告白×勇気・宣言系）
```
告白して振られた知り合いが、その日の夜に送ってきたLINE。

「振られたけど、好きって言えてよかった。
ずっと片思いのまま、好きな人に気持ちも伝えられない自分でいるより、
玉砕でも前に進めた今のほうが、ちょっと好き」

叶わない恋でも、伝えた勇気は本物だよ。
その勇気、わたしは尊敬する。
```
