# X キーワード自動DM（x-autodm）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 自分のX投稿にキーワード入りリプをしたフォロワーへ自動DMを送る CLI（`packages/x-api/autodm.mjs`）を3アカウントで動かせる状態にする。

**Architecture:** 既存 `packages/x-api`（pure HTTP の X Web GraphQL クライアント）に、純関数中心の `lib/autodm/`（keyword / state / config / cycle）と DM 送信 `lib/dm.mjs` を追加する。ネットワークは `runCycle` に注入する `deps` に閉じ込め、単体テストは fake deps とテンポラリディレクトリで回す。CLI は `runCycle` を全アカウント順次呼ぶだけの薄い層。

**Tech Stack:** Node.js 24 (ESM `.mjs`), `node:test` + `node:assert/strict`（依存追加なし）, 既存 `x-client-transaction-id` パッケージ, 既存 `lib/http.mjs` / `session.mjs` / `lib/search.mjs` / `lib/profile.mjs`。

**Spec:** `docs/superpowers/specs/2026-08-31-x-autodm-design.md`

## Global Constraints

- すべての作業ディレクトリは `packages/x-api/`。パスは断りが無ければそこからの相対。
- 非Premiumアカウント前提: DM は `followed_by === true` の相手にのみ送る。
- 安全策の固定値: ポーリング最短 **300 秒**、日次上限デフォルト **50**・最大 **500**、DM間ジッタデフォルト **30〜90 秒**、`pending` 保持 **7 日**、DM失敗 **3 回**で `failed`。
- 同一 `"<post_id>:<user_id>"` キーには二度と送らない。
- state の書き込みは tmp ファイル → `rename` でアトミック。
- `packages/x-api` は現在 git 未追跡（`?? packages/x-api/`）。各タスクの commit はそのタスクで触ったファイルだけを `git add` する。
- 依存パッケージは追加しない（`node:test` を使う）。
- 既存の動いているコード（`search.mjs` の transaction 生成など）はリファクタしない。追加のみ。

// キーワード照合. NFKC 正規化 → 小文字 → 空白除去 してから部分一致.
export function normalizeText(s) {
  return String(s ?? "").normalize("NFKC").toLowerCase().replace(/\s+/g, "");
}

/**
 * @returns {string|null} 一致した元のキーワード. 無ければ null.
 */
export function matchKeyword(text, keywords) {
  const t = normalizeText(text);
  for (const k of keywords || []) {
    const nk = normalizeText(k);
    if (nk && t.includes(nk)) return k;
  }
  return null;
}
```

// autodm の状態ファイルと jsonl ログ.
//   data/<account>/autodm_state.json  … sent / pending / failed / expired / daily / me
//   data/<account>/autodm_log.jsonl   … 1行1イベント
import { readFileSync, writeFileSync, renameSync, mkdirSync, existsSync, appendFileSync } from "fs";
import { dirname, join } from "path";
import { DEFAULT_DATA_DIR } from "../save.mjs";

export function statePath(accountName, dir = DEFAULT_DATA_DIR) {
  return join(dir, accountName, "autodm_state.json");
}
export function logPath(accountName, dir = DEFAULT_DATA_DIR) {
  return join(dir, accountName, "autodm_log.jsonl");
}

export function emptyState() {
  return { sent: {}, pending: {}, failed: {}, expired: {}, daily: {}, me: null };
}

export function loadState(path) {
  if (!existsSync(path)) return emptyState();
  return { ...emptyState(), ...JSON.parse(readFileSync(path, "utf8")) };
}

/** tmp → rename でアトミックに書く */
export function saveState(path, state) {
  mkdirSync(dirname(path), { recursive: true });
  const tmp = `${path}.${process.pid}.tmp`;
  writeFileSync(tmp, JSON.stringify(state, null, 2));
  renameSync(tmp, path);
}

export function candidateKey(postId, userId) {
  return `${postId}:${userId}`;
}

/** ローカル日付 YYYY-MM-DD */
export function dayKey(now = new Date()) {
  const y = now.getFullYear();
  const m = String(now.getMonth() + 1).padStart(2, "0");
  const d = String(now.getDate()).padStart(2, "0");
  return `${y}-${m}-${d}`;
}
export function dailyCount(state, now = new Date()) {
  return state.daily[dayKey(now)] || 0;
}
export function bumpDaily(state, now = new Date()) {
  const k = dayKey(now);
  state.daily[k] = (state.daily[k] || 0) + 1;
}

/** pendingDays を超えた pending を expired に移し、移したキーを返す */
export function expirePending(state, pendingDays, now = new Date()) {
  const cutoff = now.getTime() - pendingDays * 86400000;
  const moved = [];
  for (const [key, p] of Object.entries(state.pending)) {
    if (new Date(p.first_seen).getTime() < cutoff) {
      state.expired[key] = { at: now.toISOString(), screen_name: p.screen_name, trigger: p.trigger };
      delete state.pending[key];
      moved.push(key);
    }
  }
  return moved;
}

export function appendLog(path, event) {
  mkdirSync(dirname(path), { recursive: true });
  appendFileSync(path, JSON.stringify({ ts: new Date().toISOString(), ...event }) + "\n");
}
```

// autodm 設定 (autodm/<account>.json) の読込・デフォルト・クランプ・検証.
import { readFileSync, readdirSync, existsSync } from "fs";
import { resolve, dirname, join, basename } from "path";
import { fileURLToPath } from "url";

const __dirname = dirname(fileURLToPath(import.meta.url));
export const DEFAULT_CONFIG_DIR = resolve(__dirname, "..", "..", "autodm");

export const DEFAULTS = {
  daily_cap: 50,
  poll_interval_sec: 600,
  pending_days: 7,
  dm_delay_sec: [30, 90],
  search_max_pages: 3,
};
export const MIN_POLL_INTERVAL_SEC = 300;
export const MAX_DAILY_CAP = 500;

export function normalizeConfig(raw) {
  const c = { ...DEFAULTS, ...(raw || {}) };
  c.poll_interval_sec = Math.max(MIN_POLL_INTERVAL_SEC, Number(c.poll_interval_sec) || DEFAULTS.poll_interval_sec);
  c.daily_cap = Math.min(MAX_DAILY_CAP, Math.max(0, Number(c.daily_cap) || 0));
  c.pending_days = Math.max(0, Number(c.pending_days) || DEFAULTS.pending_days);
  if (
    !Array.isArray(c.dm_delay_sec) || c.dm_delay_sec.length !== 2 ||
    !c.dm_delay_sec.every((n) => Number.isFinite(Number(n)) && Number(n) >= 0) ||
    Number(c.dm_delay_sec[0]) > Number(c.dm_delay_sec[1])
  ) {
    c.dm_delay_sec = [...DEFAULTS.dm_delay_sec];
  } else {
    c.dm_delay_sec = c.dm_delay_sec.map(Number);
  }
  c.search_max_pages = Math.max(1, Number(c.search_max_pages) || DEFAULTS.search_max_pages);
  if (!Array.isArray(c.triggers)) throw new Error("config.triggers must be an array");
  c.triggers = c.triggers.map((t, i) => {
    if (t.post_id === undefined || t.post_id === null || t.post_id === "") throw new Error(`triggers[${i}].post_id required`);
    if (!Array.isArray(t.keywords) || t.keywords.length === 0) throw new Error(`triggers[${i}].keywords must be a non-empty array`);
    if (!t.dm_text) throw new Error(`triggers[${i}].dm_text required`);
    return {
      id: t.id || `trigger-${i}`,
      post_id: String(t.post_id),
      keywords: t.keywords.map(String),
      dm_text: String(t.dm_text),
      active: t.active !== false,
    };
  });
  return c;
}

export function configPath(accountName, dir = DEFAULT_CONFIG_DIR) {
  return join(dir, `${accountName}.json`);
}

export function loadConfig(path) {
  if (!existsSync(path)) throw new Error(`autodm config not found: ${path}`);
  return normalizeConfig(JSON.parse(readFileSync(path, "utf8")));
}

export function listConfigAccounts(dir = DEFAULT_CONFIG_DIR) {
  if (!existsSync(dir)) return [];
  return readdirSync(dir)
    .filter((f) => f.endsWith(".json") && f !== "example.json")
    .map((f) => basename(f, ".json"))
    .sort();
}
```

// DM 送信 (X Web 内部 REST: POST /i/api/1.1/dm/new2.json)
// ⚠ payload / query は 2026-08 時点の Web クライアント観測に基づく想定. 実ブラウザからの
//    送信を webtrace でキャプチャして差分があれば DM_QUERY / body を合わせる (docs/autodm.md 参照).
import { randomUUID } from "crypto";
import { authHeaders } from "../session.mjs";
import { xFetch } from "./http.mjs";
import { generateTransactionId } from "./transaction.mjs";

export const DM_PATH = "/i/api/1.1/dm/new2.json";
const DM_QUERY =
  "ext=mediaColor,altText,mediaStats,highlightedLabel,voiceInfo,birdwatchPivot,superFollowMetadata,unmentionInfo,editControl,article" +
  "&include_ext_alt_text=true&include_ext_limited_action_results=true&include_reply_count=1" +
  "&tweet_mode=extended&include_ext_views=true&include_ext_edit_control=true";

/** "<小さいID>-<大きいID>" (数値比較) */
export function conversationId(a, b) {
  const [x, y] = [String(a), String(b)].sort((p, q) => (BigInt(p) < BigInt(q) ? -1 : 1));
  return `${x}-${y}`;
}

export function buildDmRequest({ myUserId, recipientId, text, requestId = randomUUID() } = {}) {
  if (!myUserId) throw new Error("myUserId required");
  if (!recipientId) throw new Error("recipientId required");
  if (!text) throw new Error("text required");
  return {
    url: `https://x.com${DM_PATH}?${DM_QUERY}`,
    body: {
      conversation_id: conversationId(myUserId, recipientId),
      recipient_ids: false,
      request_id: requestId,
      text,
      cards_platform: "Web-12",
      include_cards: 1,
      include_quote_count: true,
      dm_users: false,
    },
  };
}

/**
 * DM を1通送る. session 切れは XSessionError、その他失敗は err.status 付き Error.
 */
export async function sendDm(acc, { recipientId, text, accountName } = {}) {
  const { url, body } = buildDmRequest({ myUserId: acc.user_id, recipientId, text });
  const tid = await generateTransactionId("POST", DM_PATH);
  const mk = (a) => ({
    method: "POST",
    headers: {
      ...authHeaders(a, { json: true, referer: "https://x.com/messages" }),
      "x-client-transaction-id": tid,
    },
    body: JSON.stringify(body),
  });
  const r = await xFetch(url, mk(acc), { accountName, rebuildHeaders: mk });
  if (!r.ok) {
    const err = new Error(`DM HTTP ${r.status}: ${(r.text || JSON.stringify(r.json) || "").slice(0, 300)}`);
    err.status = r.status;
    throw err;
  }
  return { ok: true, status: r.status, conversation_id: body.conversation_id, raw: r.json };
}

export function jitterMs([min, max]) {
  return Math.round((min + Math.random() * (max - min)) * 1000);

/**
 * リプ一覧から新規候補を抽出する純関数.
 * @returns {{ key, trigger, user_id, screen_name, reply_id, keyword }[]}
 */
export function findCandidates({ replies, triggers, myUserId, state }) {
  const byPost = new Map(triggers.filter((t) => t.active).map((t) => [t.post_id, t]));
  const out = [];
  for (const r of replies || []) {
    const trig = byPost.get(String(r.in_reply_to_status_id));
    if (!trig) continue;
    const uid = r.user?.id;
    if (!uid || String(uid) === String(myUserId)) continue;
    const key = candidateKey(trig.post_id, uid);
    if (state.sent[key] || state.failed[key] || state.expired[key] || state.pending[key]) continue;
    const keyword = matchKeyword(r.text, trig.keywords);
    if (!keyword) continue;
    out.push({ key, trigger: trig, user_id: String(uid), screen_name: r.user.screen_name, reply_id: r.id, keyword });
  }
  return out;
}

        rawQuery: `to:${screenName} -from:${screenName}`,
        product: "Latest",
        max: maxPages * 20,
        perPage: 20,
        accountName,
      });
      return tweets;
    },
    sendDm,
    sleep: (ms) => new Promise((r) => setTimeout(r, ms)),
    log: (e) => {
      const who = e.screen_name ? ` @${e.screen_name}` : "";
      console.error(`[autodm] ${e.account} ${e.event}${who}${e.error ? ` ${e.error}` : ""}`);
    },
  };
}

/**
 * 1アカウント 1サイクル.
 * @returns {Promise<{matched, pending, sent, failed, expired, capReached, sessionError?}>}
 */
export async function runCycle({ accountName, dryRun = false, deps, paths = {}, now = () => new Date() }) {
  const { getAccount, getProfile, fetchReplies, sendDm, sleep, log } = deps;
  const cfgPath = paths.config || configPath(accountName);
  const stPath = paths.state || statePath(accountName);
  const lgPath = paths.log || logPath(accountName);

  const config = loadConfig(cfgPath);
  const state = loadState(stPath);
  const summary = { matched: 0, pending: 0, sent: 0, failed: 0, expired: 0, capReached: false };
  const emit = (event, extra = {}) => {
    const e = { account: accountName, event, ...extra };
    appendLog(lgPath, e);
    if (log) log(e);
  };

  const active = config.triggers.filter((t) => t.active);
  if (active.length === 0) return summary;

  try {
    const acc = getAccount(accountName);
    const me = await getProfile(acc, { userId: acc.user_id, accountName });
    if (!me?.screen_name) throw new Error("own profile fetch failed (screen_name missing)");
    state.me = { user_id: String(me.user_id), screen_name: me.screen_name };

    // 1. 期限切れ
    for (const key of expirePending(state, config.pending_days, now())) {
      summary.expired++;
      emit("expired", { key });
    }

    // 2. 新規候補 → pending
    const replies = await fetchReplies(acc, { screenName: me.screen_name, maxPages: config.search_max_pages, accountName });
    for (const c of findCandidates({ replies, triggers: active, myUserId: state.me.user_id, state })) {
      summary.matched++;
      state.pending[c.key] = {
        first_seen: now().toISOString(), screen_name: c.screen_name, reply_id: c.reply_id,
        trigger: c.trigger.id, user_id: c.user_id, post_id: c.trigger.post_id, attempts: 0,
      };
      emit("matched", { key: c.key, trigger: c.trigger.id, post_id: c.trigger.post_id, user_id: c.user_id, screen_name: c.screen_name, keyword: c.keyword });
    }

    // 3. pending を処理: フォロー判定 → 送信
    const trigById = new Map(config.triggers.map((t) => [t.id, t]));
    for (const [key, p] of Object.entries(state.pending)) {
      const trig = trigById.get(p.trigger);
      if (!trig || !trig.active) continue;
      if (dailyCount(state, now()) >= config.daily_cap) {
        summary.capReached = true;
        emit("cap_reached", { daily_cap: config.daily_cap });
        break;
      }
      const prof = await getProfile(acc, { userId: p.user_id, accountName });
      if (!prof?.followed_by) { summary.pending++; continue; }
      if (dryRun) {
        emit("dry_run", { key, screen_name: p.screen_name, trigger: trig.id, text: trig.dm_text });
        continue;
      }
      try {
        await sleep(jitterMs(config.dm_delay_sec));
        await sendDm(acc, { recipientId: p.user_id, text: trig.dm_text, accountName });
        state.sent[key] = { at: now().toISOString(), screen_name: p.screen_name, trigger: trig.id, user_id: p.user_id, post_id: p.post_id };
        delete state.pending[key];
        bumpDaily(state, now());
        summary.sent++;
        emit("sent", { key, screen_name: p.screen_name, trigger: trig.id });
      } catch (e) {
        if (e instanceof XSessionError) throw e;
        p.attempts = (p.attempts || 0) + 1;
        p.last_error = String(e.message);
        emit("dm_failed", { key, screen_name: p.screen_name, attempts: p.attempts, error: e.message });
        if (p.attempts >= MAX_DM_ATTEMPTS) {
          state.failed[key] = { at: now().toISOString(), attempts: p.attempts, error: e.message, screen_name: p.screen_name, trigger: trig.id };
          delete state.pending[key];
          summary.failed++;
        }
        if (e.status === 429) {
          emit("rate_limited", { key });
          break;
        }
      }
    }
  } catch (e) {
    if (e instanceof XSessionError) {
      summary.sessionError = e.message;
      emit("session_error", { error: e.message });
    } else {
      throw e;
    }
  } finally {
    saveState(stPath, state);
  }
  return summary;
}
```

```js
// X キーワード自動DM
//   node autodm.mjs --account <name> [--dry-run]           1回だけ (既定)
//   node autodm.mjs --all --loop [--interval 600]          autodm/*.json の全アカウントをループ
// 設定: autodm/<account>.json (雛形: autodm/example.json)
// 状態: data/<account>/autodm_state.json / ログ: data/<account>/autodm_log.jsonl
import { runCycle, defaultDeps } from "./lib/autodm/cycle.mjs";
import { listConfigAccounts, loadConfig, configPath, MIN_POLL_INTERVAL_SEC } from "./lib/autodm/config.mjs";

const USAGE = "usage: node autodm.mjs (--account <name> | --all) [--once|--loop] [--dry-run] [--interval <sec>]";
const args = process.argv.slice(2);
let account = null, all = false, loop = false, dryRun = false, interval = null;
for (let i = 0; i < args.length; i++) {
  const a = args[i];
  if (a === "--account") account = args[++i];
  else if (a === "--all") all = true;
  else if (a === "--loop") loop = true;
  else if (a === "--once") loop = false;
  else if (a === "--dry-run") dryRun = true;
  else if (a === "--interval") interval = Number(args[++i]);
  else { console.error(`unknown arg: ${a}\n${USAGE}`); process.exit(1); }
}
const accounts = all ? listConfigAccounts() : account ? [account] : [];
if (accounts.length === 0) {
  console.error(all ? "no configs found in autodm/*.json" : USAGE);
  process.exit(1);
}

const deps = defaultDeps();

async function runAll() {
  for (const name of accounts) {
    try {
      const s = await runCycle({ accountName: name, dryRun, deps });
      console.log(JSON.stringify({ account: name, dryRun, ...s }));
    } catch (e) {
      console.error(`[autodm] ${name} error: ${e.message}`);
    }
  }
}

function nextWaitSec() {
  if (interval) return Math.max(MIN_POLL_INTERVAL_SEC, interval);
  const secs = accounts.map((n) => { try { return loadConfig(configPath(n)).poll_interval_sec; } catch { return MIN_POLL_INTERVAL_SEC; } });
  return Math.max(MIN_POLL_INTERVAL_SEC, Math.min(...secs));
}

do {
  await runAll();
  if (loop) {
    const wait = nextWaitSec();
    console.error(`[autodm] next run in ${wait}s`);
    await new Promise((r) => setTimeout(r, wait * 1000));
  }
} while (loop);
```

# autodm — キーワードリプ → 自動DM

自分の投稿に指定キーワードを含むリプをした **フォロワー** に DM を送る。非Premium前提。

## 前提（Xの仕様）

- 非Premiumは **相手が自分をフォローしている時だけ** DM を送れる。未フォローは `pending` に置き、
  `pending_days`（既定7日）の間、毎サイクル再判定する。
- X の DM 上限は 500通/日。既定 `daily_cap` は 50。
- 催促リプ等は打たない。DM本文の URL は 1 つまで推奨（スパム判定回避）。

## セットアップ

1. アカウント登録: `node login_browser.mjs --account <name>`（AGENTS.md §2）→ `node check_session.mjs --account <name>` で OK を確認
2. 設定: `cp autodm/example.json autodm/<name>.json` して編集

## 挙動の要点

- 同じ `post_id × user_id` には二度と送らない（`sent` / `failed` / `expired` に入ったら再送しない）。
- DM 失敗は 3 回で `failed`。HTTP 429 はそのサイクルを打ち切る。
- セッション切れ（`XSessionError`）はそのアカウントをスキップしてログに残す。`--loop` は止まらない。
  → `node login_browser.mjs --account <name>` で再ログイン。
- `pending` が多いと毎サイクル人数分のプロフィール取得が走る。数百人規模なら `pending_days` を短くする。
- リプ取得は `to:<me> -from:<me>` の Latest 検索（`search_max_pages` × 20件）。10分に 60 件以上リプが付く投稿では取りこぼす可能性がある → `search_max_pages` を増やす。

## DM エンドポイントについて（要検証）

`lib/dm.mjs` は Web クライアントの `POST /i/api/1.1/dm/new2.json` を再現している。X 側の変更で
query / body が変わることがあるので、送信が 400/404 で落ちる時は実ブラウザから DM を 1 通送って
リクエストをキャプチャし（`webtrace` skill か DevTools の Network タブ）、`DM_QUERY` と `buildDmRequest` の
body を合わせる。

## トラブル

| 症状 | 対処 |
|---|---|
| `X account not found` | `login_browser.mjs` でログイン |
| `autodm config not found` | `autodm/<account>.json` を作る |
| `matched` が出ない | `post_id` が正しいか / キーワードがリプ本文に含まれているか / 検索に反映されるまで数分待つ |
| `sent` が出ず pending のまま | 相手が未フォロー。`followed_by` が true になるまで待つ |
| `DM HTTP 4xx` | 上記「DM エンドポイントについて」 |
